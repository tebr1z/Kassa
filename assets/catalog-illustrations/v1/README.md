# Catalog illustrations, version 1

Generated with the built-in imagegen tool on 2026-11-14 at the merchant's request.
These are generic representations, not verified photographs of the actual SKU.
The website labels them “İllüstrativ şəkil” and asks customers to confirm the
exact appearance before ordering. Do not infer dimensions, certifications,
included accessories or model-specific design from these images.

Final assets: `grill.webp`, `chopper.webp`, `grater.webp`, each a 1000px square
WebP re-encoding of a reviewed original. Originals are retained. Media identities
are in `lib/catalog-illustrations.ts`.
